# Debug Project — Lista de Tareas

Este proyecto fue generado por IA como parte del curso **"Dirigir IA para construir productos web reales"**.

## Tu misión

Esta app de lista de tareas fue creada con inteligencia artificial. Tiene **3 bugs** que la hacen funcionar mal. Tu trabajo es diagnosticar cada error y escribir el prompt para corregirlo.

## Cómo usarlo

1. Descarga o clona este repositorio
2. Abre `index.html` en tu navegador (o usa Live Server en VS Code)
3. Prueba la app y observa los 3 síntomas
4. Usa tu IA para diagnosticar la causa de cada bug y corregirlo

## Los 3 síntomas que vas a notar

1. **Agrego una tarea pero no aparece nada en la lista**
2. **El botón "Eliminar" no hace nada al hacer clic**
3. **Al marcar una tarea como completada no hay ningún cambio visual**

> **Importante:** Observa los síntomas, luego revisa el código con tu IA. Describe exactamente lo que ves y pídele que encuentre la causa.
